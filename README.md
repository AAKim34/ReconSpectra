The main code is located in the "torchSpec.ipynb" file. it contains neural network training, validation, and testing. The code for comparing experimental and reconstructed spectra is also implemented in this notebook.
The "dataSET-2.ipynb" file contains code for creating an artificial dataset.
An already aggregated dataset for neural network training is available at the link: https://drive.google.com/file/d/1SxtevD9d92Yz5NFg6Kz6BV5HYnFUAFg2/view?usp=share_link
The file "trainClasses.py" contains the neural network architecture, as well as additional classes for training (such as normalization, augmentation, etc.).
The file "modeules.py" contains helper functions.
The folder "tables" contains a database generated in Geant4.
All Excel tables in the root folder are data used for modeling in Geant4 for model verification.
